# Freskio

**Freskio** es un emprendimiento de startup tecnológica que desarrolla un frutero inteligente para ayudar a conservar frutas tropicales en condiciones adecuadas según las necesidades específicas de cada tipo de fruta.

## ¿Qué es Freskio?

El proyecto consiste en un prototipo funcional que integra hardware, sensores, inteligencia artificial (IA) y una aplicación móvil. Su propósito es crear un entorno de conservación adaptable: el sistema monitorea variables ambientales y ajusta las condiciones necesarias para favorecer la conservación de las frutas.

## ¿Cómo funciona?

El frutero inteligente utiliza sensores para medir variables como:

- **pH**
- **Humedad**
- **Temperatura**
- **Nivel de oxígeno**
- **Nivel de nitrógeno**

Con la información recopilada, el sistema permite supervisar las condiciones internas y acondicionar la temperatura y el nivel de oxígeno de acuerdo con el tipo de fruta. La inteligencia artificial y la aplicación móvil forman parte de la solución para apoyar el monitoreo y la gestión del dispositivo.

## Objetivo

Desarrollar una solución tecnológica que contribuya a conservar mejor las frutas tropicales, adaptando las condiciones de almacenamiento a sus características y necesidades particulares.

## Estado del proyecto

Freskio cuenta con un **prototipo funcional**. Este repositorio servirá para documentar su desarrollo, registrar avances y organizar la información técnica del proyecto.
